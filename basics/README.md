## 一句话概括

> **模型决定智能的上限，Harness 决定你能把多少智能用出来。**
> 同一个模型，套上不同的脚手架（循环、工具、记忆、评测），在 SWE-bench 等真实任务上的
> 表现可以相差数倍——这正是 harness 研究价值所在。
